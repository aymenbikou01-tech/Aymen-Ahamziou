# HEXA 73 — Personal Portfolio

A responsive static portfolio for Aymen Ahamziou, known online as HEXA 73.

## Files
- `index.html` — semantic page content and metadata
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and dynamic footer year
- `assets/` — favicon and social preview graphic
- `robots.txt` and `sitemap.xml` — replace placeholder domain after publishing

## Run locally
Open this folder in VS Code and use Live Server, or open `index.html` directly in a browser.

## Before publishing
1. Search the project for `YOUR-DOMAIN.example` and replace it with your real public domain or hosting URL in `robots.txt` and `sitemap.xml`.
2. Replace generic GitHub, LinkedIn, and Instagram links with your actual public profile URLs.
3. Confirm the email address is one you want to publish publicly.
4. Replace starter project descriptions/links with real projects. Do not claim work, numbers, or security tests you cannot substantiate.
5. Add your own portrait only if you want it public. Do not publish private information.
6. Validate the site on desktop and mobile.

## Deploy
This is a static site and can be deployed on Cloudflare Pages, GitHub Pages, or another static host. No build command is required; the project root is the deployment directory.

## Discoverability
The page includes a title, description, Open Graph metadata, and basic Schema.org Person structured data. These help search systems interpret the page but do not guarantee indexing or AI answers.
